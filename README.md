# Animals Filter · сайт приложения

Статические страницы поддержки для iOS-приложения Animals Filter (определение питомца по фото).

- `index.html` – витрина: что делает приложение.
- `privacy.html` – политика конфиденциальности, обязательная ссылка в карточке App Store.
- `support.html` – страница поддержки, вторая обязательная ссылка.

Сборки нет: правка html и есть правка сайта. Код самого приложения лежит в репозитории animals-filter.
